# 影子借步 · 影子踩开关 / Shadow Borrow Step — Shadow on Switch

原创离线益智小游戏原型（**20 关**）。你每走一步，影子自动往**相反方向**走一步。场上只有**一个出口**；出口的门默认锁着，必须让**影子踩住开关**门才会开，你才能走进出口通关。

An original offline puzzle prototype (**20 levels**). Every step you take, your shadow moves the **opposite** way. There is **one exit**. The door stays locked until the **shadow stands on the switch**; then you may step into the exit to win.

## 怎么玩 / How to play

1. **移动**：键盘方向键或 WASD；手机可滑动棋盘 / 点下方十字键。
2. **反向**：你↑影子↓，你←影子→，以此类推。
3. **开关与门**：影子站在**橙色开关**上 → 门打开（绿色出口）；影子离开 → 门立刻上锁。
4. **通关**：在门开着时，玩家走进**出口**。
5. **钉住**：影子若会撞墙 / 出界 / 逆向单向道，则**停在原地**，你仍可移动——用来把影子钉在开关上。
6. **失败 / 阻挡**：你撞墙、出界、踩刺、逆向单向道，或影子踩刺 → 该步无效；两人重叠 → 挡住。可**撤销**或**重开**。

## 特殊格 / Special tiles

| 符号 | 名称 | 效果 |
|------|------|------|
| `I` | 冰 Ice | 踩上后沿本次移动方向一直滑到不能再滑 |
| `U/D/L/R` | 弹跳 Jump | 朝箭头方向**跳两格**（可越过中间尖刺）；若两格不可达则尝试一格 |
| `> < ^ v` | 单向 One-way | 只能沿箭头方向踩上去；影子逆向则视为撞墙并钉住 |
| `A` / `@` | 传送 Portal | `A` 与 `@`（或 `B`）成对；踩上一扇传到另一扇。`@` = 传送落点且为出口 |

前几关教基础与钉开关；中期引入冰 / 弹跳 / 单向；11 关起有传送门，并开始对提示收「广告」。

## 进度与提示 / Progression & hints

- **顺序解锁**：只能从第 1 关玩到当前最高通关+1；中间不能跳关。已通关关卡可重玩。
- **本地存档**：`localStorage` 键 `shadow-borrow-step-progress`，字段 `maxCleared`（最高通关关卡号）、`cleared`（已通关索引数组）。
- **提示**：局内「提示」按钮（或按 `H`）。对应当前局面 BFS 下一步方向，并在棋盘高亮箭头。
  - **第 1–10 关**：提示免费。
  - **第 11–20 关**：首次使用提示需先看**模拟广告**（弹窗「观看广告中…」约 2.5 秒倒计时 →「广告结束，提示已解锁」）。本会话该关提示解锁后可重复查看，无需再看广告。无真实 AdMob。

## 本地打开 / Open locally

```bash
cd shadow-borrow-step
python3 -m http.server 8080
# http://localhost:8080
```

或直接打开 `index.html`。

## 文件

- `index.html` — 页面（含提示 / 广告 / 通关弹层）
- `css/style.css` — 深色手机友好样式
- `js/levels.js` — 20 关（含预存解与提示文案，BFS 验证可解）
- `js/game.js` — 逻辑、特殊格、撤销、顺序解锁、提示、模拟广告

## 设计取舍

- **唯一目标**：只盯玩家出口；影子是开门工具。
- **影子撞墙停住**：实现「先钉开关，再出门」。
- **弹跳两格**：可越过尖刺，形成「跳过刺」关卡。
- **锁门不可进**：出口格在影子未踩开关时不可进入。
- 纯 HTML/CSS/JS，无外部资源、无联网（广告仅为本地倒计时模拟）。
